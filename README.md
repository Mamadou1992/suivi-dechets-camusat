# Dossier de donnees locales

Deposer ici les fiches de collecte Excel historiques (un onglet par semaine).
Elles sont lues automatiquement au demarrage de l'application et fusionnees
avec les soumissions KoboToolbox.

Ce dossier est exclu du depot Git (`.gitignore`) : les fichiers contenant des
donnees Camusat / SONAGED ne doivent pas etre publies sur un depot public.
